# Cryptography Lab Setup

## Objective
To understand the basics of cryptography and learn how to protect information using encryption and decryption techniques.

## Lab Requirements
- Kali Linux
- Terminal
- OpenSSL
- Basic Linux commands

## Introduction
Cryptography is the technique of securing information by converting readable data (plaintext) into an unreadable format (ciphertext) to prevent unauthorized access.

It is used to protect passwords, files, messages, network communication, and sensitive information.

## Types of Cryptography

### 1. Symmetric Encryption
Symmetric encryption uses the same key for both encryption and decryption.

Example: AES (Advanced Encryption Standard).

### 2. Asymmetric Encryption
Asymmetric encryption uses two keys:
- Public key – used for encryption or signature verification.
- Private key – used for decryption or digital signing.

Example: RSA.

### 3. Hashing
Hashing converts data into a fixed-length value. It is generally used for integrity verification and password storage, not for reversible encryption.

Examples: SHA-256, SHA-512.
