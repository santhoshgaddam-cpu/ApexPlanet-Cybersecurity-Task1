# Cybersecurity Task 1 – Linux & Security Fundamentals

## About This Repository

This repository contains my beginner-level cybersecurity learning notes, Linux command cheat sheet, networking fundamentals, cryptography concepts, and documentation of my practical cybersecurity lab setup.

The purpose of this repository is to organize my learning materials and document my hands-on experience with Linux and basic cybersecurity tools.

## Objectives

- Understand Linux fundamentals and terminal commands.
- Learn basic file and directory management.
- Practice Linux permissions.
- Understand networking concepts.
- Learn basic cryptography concepts.
- Become familiar with Kali Linux.
- Understand the purpose of Wireshark.
- Document a virtual cybersecurity lab environment.

## Topics Covered

- Linux commands
- Linux file permissions
- Cybersecurity fundamentals
- Networking fundamentals
- TCP/IP and common ports
- Cryptography and hashing
- Kali Linux lab setup
- Wireshark basics
