# Linux Command Cheat Sheet – Kali Linux

**File System Navigation**
- `pwd` – Displays the current working directory.
- `ls` – Lists files and directories.
- `ls -la` – Lists all files, including hidden files, with details.
- `cd` – Changes the current directory.
- `mkdir` – Creates a new directory.
- `touch` – Creates a new empty file.

**File & Directory Permissions**
- `chmod` – Changes file permissions.
- `chown` – Changes file ownership.
- `ls -l` – Displays file permissions and ownership.

**Package Management**
- `sudo apt update` – Updates package repository information.
- `sudo apt upgrade` – Upgrades installed packages.
- `sudo apt install` – Installs software packages.
- `sudo apt remove` – Removes installed packages.
- `dpkg -l` – Lists installed packages.
- `dpkg -i` – Installs a Debian package (.deb).

**Networking Commands**
- `ifconfig` – Displays network interface configuration.
- `ip addr` – Displays IP addresses and network interfaces.
- `ping` – Tests network connectivity.
- `netstat -tulnp` – Displays listening ports and network connections.
- `traceroute` – Traces the route to a destination.

**Useful System Commands**
- `clear` – Clears the terminal screen.
- `whoami` – Displays the current username.
- `sudo` – Executes commands with administrative privileges.
- `man` – Displays the manual page for a command.
- `exit` – Closes the terminal session.
