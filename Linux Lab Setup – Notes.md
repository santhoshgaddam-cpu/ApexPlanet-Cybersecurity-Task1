# Kali Linux Lab Setup – Notes

## Objective
To set up a Kali Linux virtual machine and practice basic Linux commands, file management, permissions, and networking in a cybersecurity lab environment.

## Lab Environment
- **Operating System:** Kali Linux
- **Virtualization Software:** Oracle VirtualBox
- **Host OS:** Windows 11
- **Lab Type:** Virtual cybersecurity lab

## Tasks Performed

### 1. Linux File System Navigation
Commands practiced:
- `pwd` – Display the current working directory.
- `ls` – List files and directories.
- `ls -la` – Display all files, including hidden files.
- `cd` – Change the current directory.
- `mkdir` – Create a new directory.

### 2. File and Directory Permissions
Commands practiced:
- `chmod` – Modify file permissions.
- `chown` – Change file ownership.
- `ls -l` – View file permissions.

Example:
`chmod 755 test.txt`

### 3. Package Management
Commands practiced:
- `sudo apt update` – Update package information.
- `sudo apt upgrade` – Upgrade installed packages.
- `sudo apt install package_name` – Install a package.

### 4. Networking Commands
Commands practiced:
- `ip addr` – View network interface details and IP addresses.
- `ping` – Check connectivity.
- `netstat` – Display network connections.
- `traceroute` – Trace the route to a destination.

### 5. Lab Practice
- Created folders and files in Kali Linux.
- Practiced changing file permissions.
- Explored Linux directory structure.
- Checked network interfaces and IP configuration.
- Practiced basic terminal commands.

## Conclusion
Successfully set up a Kali Linux virtual lab environment and practiced basic Linux commands, file system navigation, file permissions, package management, and networking commands. This lab provided a foundation for further cybersecurity and ethical hacking practice.
